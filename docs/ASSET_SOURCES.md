# Asset sources

## Temporary Striker model

The demo currently loads the existing character from:

`https://raw.githubusercontent.com/badbuny126-png/-poca-tok-2026/main/public/models/player.glb`

This avoids copying the old repository's duplicate archives and oversized root assets. For a self-contained release, upload the same model as:

`public/assets/characters/striker/striker.glb`

Then replace `STRIKER_MODEL` in `src/main.js` with:

`./assets/characters/striker/striker.glb`

## Arena

The court is generated by `src/court.js`. No old arena mesh is required. Replace it with modular optimized GLB pieces only when the Phase 2 arena art is ready.
